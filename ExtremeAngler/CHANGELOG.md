# Changelog

## 1.0.0

First public release.

- One key fishing: the same key casts and catches.
- Smart Cast: each press does the next thing you need - equip pole, apply lure, cast, catch.
- Automatic fishing pole swap and lure application, lure warnings.
- Auto loot and a splash-friendly sound profile while fishing; settings restored afterwards.
- Stats card: skill bar, session stats, zone loot table with icons and percentages.
- Bite timer that learns when fish usually bite.
- Notification cards: new catch, rare catch, skill up, session summary, with selectable sounds.
- Settings panel, movable and lockable UI, sleep mode when turned off.
